# Pillowfen 1.0 TEST
Native Java/Canvas Android 8+ Shugaku oriented-bed and corridor puzzle.

Place two-cell beds: tap a pillow, then an empty foot tile left, right or ABOVE it. Vertical pillows must be below their feet. Tap any bed half to remove it. Uncovered non-pillar tiles are floor automatically. Numbered pillars count ONLY side-neighbor pillows. All floor must connect by edges, never cover a 2x2 block, and every bed must touch floor along at least one side. Pillars are not floor. Beds may touch each other. Twelve unique 4x4 pillar-clue layouts and twelve distinct fully oriented bed solutions.

Saved bed palette and bed marks, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java coordinate/set oracle exhaustively enumerates all nonoverlapping oriented bed placements per board plus 20000 mutated arrays per board against production bitset connectivity, pair markers and local checks. Exactly one solution each. Bounds, wrong-length rejection, solve, undo and replay pass. Adapter menu, settings, privacy, bed placement, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current registry803, 109 recovered READMEs and recent cumulative stages/releases found no Shugaku match. Pillowmath is unrelated sewing arithmetic. Shares Twinmarsh domino placement and Cloudball typed pieces, but oriented pillow-foot pairing, pillow-neighbor clues, per-bed floor access and a connected no2x2 floor replace isolated room dominoes or opposite gravity chains.
